# Script-Controlled-ACL---Restrict-Record-Access-Based-on-Field-Value
In this milestone we have to create Users and Roles as per the requirement

## Project Description

In this milestone, we create Users and Roles as per the project requirements. 
The main purpose of this project is to control record access based on specific field values using Script-Controlled Access Control Lists (ACLs).

## Objective

- Create users as required.
- Create and assign appropriate roles.
- Configure ACLs for record-level access.
- Restrict access based on field values.
- Ensure that only authorized users can view or access specific records.

## Key Features

- User Creation
- Role Creation
- Role Assignment
- Script-Controlled ACL
- Field-Based Record Access Restriction
- Secure Record Access

## Technologies Used

- ServiceNow
- Access Control Lists (ACLs)
- JavaScript
- Users and Roles

## Implementation Steps

1. Create the required Users.
2. Create the required Roles.
3. Assign roles to the appropriate users.
4. Configure the required ACL.
5. Add the script condition based on the field value.
6. Test the ACL using different users.
7. Verify that unauthorized users cannot access restricted records.

## Expected Result

The ACL should allow users to access records only when the specified field value satisfies the defined condition. Users without the required permission should be restricted from accessing the records.

## Conclusion

This project demonstrates how Script-Controlled ACLs can be used in ServiceNow to provide secure and field-based record access. It helps ensure that users can access only the records permitted by the defined security rules.
